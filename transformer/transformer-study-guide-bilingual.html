0为什么会有 Transformer 老师讲的

在 Transformer 之前，处理句子的标准做法是 RNN / LSTM 编码器-解码器（Encoder-Decoder）：把整句话一个词一个词地"读"进一个固定大小的向量里，再从这个向量"吐"出翻译结果。

类比
这就像让你听完一整段话，只许记住一句话摘要，然后凭这句摘要去回答后面所有问题——句子一长，细节肯定丢光。

老师在 PDF 第 114 页指出：固定大小表示难以承载长句，LSTM 也难记住很久以前的信息。另一个结构性限制是序列计算：

  • 固定大小的向量装不下长句子 a fixed-size representation doesn't scale
  • 必须按顺序一步步算，没法并行补充：同一序列的状态有前后依赖，不能像 Transformer 那样并行计算所有位置；不同样本仍可批处理

第一步修正方案是 Attention：解码器每生成一个词，不再只看那一个"摘要向量"，而是回头去看编码器每一个位置的隐藏状态，按需加权。

1Attention 机制 老师讲的

核心思想：解码器在生成第 i 个词时，给编码器的每一个输入位置 j 打一个"相关度分数"，再按这个分数做加权平均，而不是只用一个固定向量。

eij = f(h̄i, hj) // 未归一化的"相关度"分数，h̄_i 是解码器状态，h_j 是编码器第 j 个位置的状态

αij = softmaxj(eij) // 归一化成一个概率分布（权重加起来=1）

ci = Σj αij hj // 按权重把所有 h_j 加权求和，得到"上下文向量" context vector

老师在 PDF 第 142–145 页给了三种打分方式。下表把加性打分补写完整：tanh 后还需投影成标量，才能用于每个输入位置的 softmax。

名称公式提出者
Additive（加性）vaᵗ tanh(Wa[h̄i; hj] + ba)Bahdanau et al. 2014
Dot product（点积）h̄i · hjLuong et al. 2015
Bilinear（双线性）h̄iᵗ W hjLuong et al. 2015
类比
这就像开卷考试：你不需要死记整本书（固定向量），每道题你都可以快速翻书，找到跟这道题最相关的那几页（高权重的 h_j），重点看那几页。

这一步之后，编码器的隐藏状态开始专门负责"表达每个词的含义"，解码器的隐藏状态专门负责"决定该看哪里"——这个分工思想直接导向了下一步：如果"查找相关内容"这件事这么好用，为什么不让句子内部的词互相之间也做这件事？ 这就是 Self-Attention。

2Self-Attention 老师讲的

Self-Attention 的意思是：Q/K/V 来自同一序列；在这里的双向例子中，每个位置可以关注整句（包括自己），用来重新计算出一个"更懂上下文"的自己。

αi,j = softmaxj(xiᵗ xj) // 词 i 对词 j 的注意力权重

x'i = Σj αi,j xj // 词 i 的新表示 = 所有词的加权平均
类比
一个教室里每个学生（词）都抬头看一遍全班所有同学（包括自己），根据"跟我讨论的话题相关不相关"决定听谁讲得多一点，然后把听到的内容融合进自己的笔记里——这一轮下来，每个人的笔记都融入了全班的上下文。

依照老师 PDF 第 156 页重绘的简化示意（Q=K=V=X，省略缩放）。权重仅用于讲解，不是模型实测，也不代表固定语言关系。标准 Transformer 加权的是投影后的 V。

补充
注意这里 Self-Attention 跟 RNN/CNN 最大的区别：句子中任意两个词之间的"距离"都是 1 步（直接算点积），不管它们隔了多远；而 RNN 要挨个传递隐藏状态，CNN 要叠很多层卷积才能让两个远的词"看到"对方。这就是 Transformer 擅长捕捉长距离依赖的根本原因。同一层所有位置都使用上一层已知的表示，可以同时计算，没有 RNN 同层沿序列的递推依赖；这有利于训练并行化。它们并非统计独立，稠密注意力的打分与聚合通常需 O(n²d) 运算，速度优势取决于序列长度、硬件和实现。

3Q / K / V 三个角色 补充

老师的公式里直接用 xiᵗxj 算分数，这是简化版。真正的 Transformer 论文（Vaswani et al. 2017）里，每个词会先被投影成三个不同的向量，分别叫 Query（查询）、Key（钥匙/标签）、Value（内容）：

Q
我在找什么？
"我是哪个词，我想了解和我相关的信息"
K
我能提供什么标签？
别人用它来判断"我跟你相关吗"
V
如果你选中我，给你什么内容？
实际被加权求和的内容
类比：图书馆检索
Query = 你在搜索框里输入的关键词；Key = 每本书书脊上贴的标签；Value = 书里真正的内容。系统拿你的 Query 去跟每本书的 Key 比对相似度，算出一个"相关度"，然后按相关度把各本书的 Value（内容）加权混合给你——越相关的书，内容占比越大。
Q = X WQ   K = X WK   V = X WV // X 是本层输入表示矩阵（每行一个 token；后续层是上一层的输出），W_Q/W_K/W_V 是可学习的参数

Attention(Q, K, V) = softmax(Q Kᵗ / √dk) V // 标准公式，见下一节

对照老师的简化公式：Q=K=V=X，省略投影与缩放，就得到 xiᵗxj。但老师的 Wk 不是标准 WK：它是第 k 个头的双线性打分矩阵，同时概括 Query 与 Key 的投影。若使用列向量 q=Akx、k=Bkx，则 qiᵗkj=xiᵗAkᵗBkxj，对应 Wk=AkᵗBk；缩放因子另行加入。老师的 Vk 则负责 Value 变换。这里的小写 k 是头的编号。

常考点
面试高频问题："为什么要分成 Q/K/V 三个向量，而不是直接用词向量本身做点积？" 答案：分开之后模型可以学到"我想找什么"（Q）和"我能被怎样找到"（K）是两件不同的事，也让"查找用的向量"和"被加权求和的内容向量"（V）解耦，模型表达能力更强。

4Scaled Dot-Product 补充

老师的幻灯片写的是 softmax(xiᵗxj)，没有写缩放因子。但原论文的公式其实是：

Attention(Q, K, V) = softmax( Q Kᵗ / √dk ) V

为什么要除以 √dk（dk 是 Key 向量的维度，比如 64）？

补充：直觉解释
在各分量独立、均值 0、方差 1 的理想化假设下，点积方差为 dk，除以 √dk 后方差为 1。实际 Q/K 是学出来的，不一定严格满足这些假设；这个推导解释了缩放的动机。如果不缩放，维度一高，点积值就会特别大或特别小，送进 softmax 后会变得"非常尖锐"（几乎只有一个词权重接近 1，其他全接近 0），可能使 softmax 的梯度很小，训练变困难。除以 √dk 相当于把点积的数值范围"拉回正常区间"，让 softmax 的输出更平滑，训练更稳定。
常考点
"Transformer 里为什么要除以 √d_k？" 是非常经典的面试题，一定要能讲清楚"维度越高点积方差越大 → softmax 饱和 → 梯度消失"这个链条。

5Multi-Head Attention 老师讲的

老师的类比很好："多个头就像多个不同的卷积滤波器（convolutional filters）"——每个头用自己独立的一套 WQ, WK, WV，分别去关注句子里不同类型的关系。

老师的简化写法（列向量）：
headk: αk,i,j = softmaxj(xiᵗ Wk xj)   x'k,i = Σj αk,i,j Vk xj
类比
一个头可能专门学会"关注前一个词"（语法关系），另一个头可能专门学会"关注指代对象"（比如 "it" 指向哪个名词），还有的头关注"长距离的主谓关系"。多个头并行工作，最后把结果拼接（concat）起来，再过一个线性层融合——相当于多个专家同时看同一句话，各自给出意见，再汇总。
补充
标准多头先用不同的可学习投影把整个输入映射到各个头，并非直接切开原始向量。原论文 Base：Encoder 和 Decoder 各 6 层，dmodel=512，h=8，dk=dv=64；Big：各 6 层，dmodel=1024，h=16，每头仍为 64。老师第 163 页的“1000 维”是近似说法。固定总维度时，多头与一个同总维度的头计算量相近。
headr = Attention(XWQr, XWKr, XWVr)
MultiHead(X) = Concat(head1, …, headh) WO

6Positional Encoding 老师讲的

没有位置编码或其他位置信号、且没有 causal mask 的 Self-Attention 是置换等变的：把输入 token 重排，输出也会按同样顺序重排，它无法仅凭内容区分先后关系。因此不能简单说所有输出向量都一样；若再做不含顺序信息的池化，两种排列才会得到相同的汇总结果。

老师给的解法：给每个词的 embedding 加上一个"位置编码"（positional embedding），每一维都是不同频率的 sin/cos 波：

PE(pos, 2i)  = sin(pos / 100002i/d)
PE(pos, 2i+1) = cos(pos / 100002i/d)

老师第 161 页的“距离近，点积高”可以当直觉，但不能当成严格单调规律。正弦位置编码的点积为 Σi cos((p−q)/100002i/d)，取决于相对距离，却会振荡；更近不保证每次都更大。老师还写了 one-hot 位置编码效果相近；原论文实际比较的是可学习位置 embedding与固定 sin/cos，结果接近。one-hot 经可学习矩阵投影可等价于 embedding 查表，不能把原始 one-hot 直接等同于同维 sin/cos。

补充
现代很多模型（比如 GPT-NeoX、LLaMA）已经不用这种"绝对位置的 sin/cos"编码了，而是用 RoPE（旋转位置编码） 等"相对位置编码"方法，直接把位置信息编码进 Q/K 的旋转变换里，让注意力打分包含相对位置信息；长文本外推仍取决于训练长度、频率设置与扩展方法，并非自动保证。这个知道名字即可，老师的课没有覆盖到这部分，属于"更新知识"。

7Transformer 完整模块 老师有结构图；这里补全说明

老师第 161 页左侧已经画出了 Encoder 的 Attention、FFN 和两次 Add & Norm；第 162 页补充说明 Encoder/Decoder 都是 Transformer。下面把图中的数据流写清楚。

原始 2017 Transformer 的 Post-LN Encoder Block 由两个子层组成，每个子层都带有 残差连接（Residual Connection） 和 Layer Normalization：

输入 x
Multi-Head Self-Attention
Add (残差: x + Attention(x)) → LayerNorm
Feed-Forward Network (原版：两层线性 + ReLU)
Add (残差) → LayerNorm
输出 → 送进下一层 Encoder Block
z = LayerNorm(x + SelfAttention(x))
out = LayerNorm(z + FFN(z))    // FFN(z) = max(0, zW₁+b₁)W₂+b₂；省略 dropout
原版与常见变体
上图是 Post-LN：先残差相加，再归一化。常见 Pre-LN 则是 z=x+Attention(LN(x))，out=z+FFN(LN(z))；有些模型使用 RMSNorm、GELU 或门控 FFN。不能把原版 Block 当作所有 LLM 的精确结构。
为什么要残差连接？
Transformer 一般要叠 6~24 层甚至上百层，网络太深，梯度传到前面会消失/爆炸。残差连接的意思是"输出 = 这一层学到的修正量 + 原始输入本身"，相当于给梯度开了一条"高速公路"，可以直接跳过这一层传回去，训练深层网络就稳定多了。这跟 ResNet 的残差思想完全一样。
为什么要 LayerNorm？
对每个 token 的隐藏维度计算均值与方差，再做归一化及可学习的缩放 γ、偏移 β：LN(x)=γ⊙(x−μ)/√(σ²+ε)+β。最终输出不保证均值 0、方差 1。LayerNorm 不依赖 batch 统计量，适合序列建模；BatchNorm 通常沿 batch 及相关空间维度统计每个通道。
补充
Feed-Forward 子层（FFN）容易被忽略，但在原版 Encoder Block 中，若 dff=4d，则 FFN 权重约 8d²、Attention 投影约 4d²，FFN 约占该 Block 权重的 2/3（忽略偏置和归一化；整个模型的比例还受 embedding 等影响）。它对每个位置独立地做"升维再降维"的非线性变换（比如 512 → 2048 → 512），可以理解为：Attention 负责"词与词之间交换信息"，FFN 负责"每个词自己消化、加工刚拿到的信息"。同一层 FFN 的参数在不同 token 位置之间共享。

8Decoder：Masked Self-Attention + Cross-Attention 补充

老师说了一句很重要的话："Decoder 消费之前生成的 token（并且会 attend 输入），但没有循环状态（recurrent state）"——这句话里藏了两个机制，老师没有展开讲清楚，这里补全：

目标 token embedding + 位置编码
训练：正确目标右移；推理：已生成的前缀
Masked Multi-Head Self-Attention (只能看自己和前面的词)
Add & LayerNorm
Cross-Attention (Query 来自 Decoder，Key/Value 来自 Encoder 输出)
Add & LayerNorm
Feed-Forward Network
Add & LayerNorm
上述三个子层组成一个 Decoder Block，重复 N 层
最后 → Linear（映射到词表）→ softmax → 下一个 token

这是 Encoder–Decoder 架构的 Decoder。GPT 的 Decoder-only Block 通常没有这里的 Cross-Attention 子层；它用同一条因果序列处理提示和输出。图中每次 Add 的旁路来自该子层输入，LayerNorm 是原版 Post-LN 顺序。

① Masked（Causal）Self-Attention

训练时，Decoder 的输入张量包含右移后的目标序列（比如输入 <BOS>, le, film, était, bon），但如果不做限制，预测 le 的位置就能读到后面的 le 本身及其他目标词——这是作弊。解决办法：在算 softmax 之前，把"未来位置"的分数强行设成 -∞，softmax 后它们的权重就变成 0。

scorei,j = (QKᵗ/√dk)i,j   if j ≤ i, else -∞
类比
就像考试的时候用一张纸把答题卡后面的题目全部盖住，你写第 3 题的时候，物理上根本看不到第 4 题写了什么——这对齐了训练和推理的可见位置范围；训练前缀来自正确答案，推理前缀来自模型生成，两者仍有分布差异（exposure bias）。

② Cross-Attention（编码器-解码器注意力）

这才是真正对应老师在第 1 节讲的 Bahdanau/Luong Attention！在 Decoder 的每一层，还有一个 attention 子层：Query 来自 Decoder 自己当前的状态，但 Key 和 Value 来自 Encoder 最后一层的输出。这正是"解码器在生成每个词时，回头去看输入句子里相关的部分"——跟老师第 1 节讲的 RNN Attention 是同一个思想，只是从 RNN 搬到了 Transformer 里，公式形式统一成了 Q/K/V。

子层Query 来自Key/Value 来自作用
Encoder Self-Attention输入句子自己输入句子自己理解输入句子内部关系
Decoder Masked Self-Attention目标前缀的本层表示目标前缀（允许当前位置及之前；输入已右移）理解目标前缀；训练时前缀来自正确答案
Decoder Cross-AttentionDecoder 当前状态Encoder 的输出决定该看输入句子的哪部分（对应老师第1节讲的 Attention）

9训练 vs 推理：Teacher Forcing 老师讲的（在 RNN 部分）

这部分老师是在 RNN encoder-decoder 那一节讲的，但对 Transformer 的 Decoder 同样适用：

  • 训练时：不管模型自己预测对不对，都把"正确答案"的前一个词喂给模型去预测下一个词（这叫 Teacher Forcing），对 Transformer，配合 causal mask 可并行计算各位置 loss；RNN 即使用 Teacher Forcing，隐藏状态仍需沿序列递推。
  • 推理时：没有正确答案可以喂，只能把模型自己刚生成的词当作下一步的输入，一步一步（autoregressive）往后生成，直到生成结束 token（老师记作 [STOP]，常记作 EOS）或达到长度限制。
右移输入示意：每一列用输入前缀预测该列标签
位置01234
Decoder 输入<BOS>lefilmétaitbon
预测标签lefilmétaitbon<EOS>
训练目标: max Σ(x,y) Σi log P(y*i | x, y*1, ..., y*i-1)
常考点
"为什么 Transformer 训练可以并行，推理却不能？" 答案：训练时因为用 Teacher Forcing + Masked Attention，整句目标句子的所有位置可以同时算（只是被 mask 限制了信息流向），一次前向传播出所有位置的 loss；但推理时第 i 个词到底是什么要等模型真正生成出来才知道，所以必须一步一步串行生成。

10Tokenization：BPE / WordPiece 补充算法（老师提到 WordPiece）

老师第 185 页明确写了 BERT 使用约 30k WordPiece token，但没有展开分词算法。Transformer 的输入单位是 token；BERT/GPT 常用子词或字节级分词，一个 token 可以是完整单词、词的一部分、标点或空白片段。架构本身并不规定必须用某一种分词方式。

为什么不直接按单词切？
如果按整个单词建词表，词表会非常大（英语单词几十万个，还有拼写错误、新词、不同语言），未登录词通常只能映射为 [UNK]，会丢失其身份信息。子词能组合出许多未见过的单词；字符词表覆盖不足时仍可能出现 [UNK]，覆盖全部字节的分词方案可避免这一类词表覆盖问题。

两种最常见的子词算法：

  • BPE（Byte Pair Encoding，字节对编码）：GPT 系列用的方法。字符级 BPE 先从字符单元开始；GPT-2 使用的字节级 BPE 则从字节单元开始，然后统计语料里出现频率最高的"相邻 token 对"，把它们合并成一个新 token，重复这个过程直到词表达到目标大小。常见的词（the, movie）会变成一个完整 token，罕见词会被拆成几个子词片段（示意 "unhappiness" → "un" + "happi" + "ness"；实际切法取决于具体 tokenizer）。
  • WordPiece：BERT 用的方法，思路跟 BPE 类似（也是逐步合并），通常用词表语言模型的似然来解释其训练思想，不应把它等同于 Transformer 语言模型的似然。原始 BERT 公开了 tokenizer 与词表，但未公开完整词表训练实现；教学中常用 freq(ab)/(freq(a)freq(b)) 来示意合并评分，它不是可确认的 BERT 原始训练规则。BERT 的输入里你能看到像 ##ing 这种片段，## 表示"这是接在前一个片段后面的子词，不是一个独立单词的开头"。
常考点
"为什么 LLM 的输入是 token 而不是单词？" + "子词分词解决了什么问题？"（词表大小可控 + 能处理没见过的词/拼写变体）是基础但高频的面试题。

11Transformer 家族：BERT / GPT / T5 老师讲的

Transformer 架构定下来之后（2017），接下来几年的大模型本质上是在"怎么用这套架构 + 怎么预训练"上做文章。

BERT（2018，Google）— Encoder-only

  • 老师强调的关键区别：ELMo 使用前向和后向两个单向 LSTM 语言模型，组合两个方向的表示，因此整体是 bidirectional LM；但两个方向在各自深层中分开建模。GPT 是从左到右的单向模型，而 BERT 是真正双向的——用 Transformer Encoder（没有 causal mask），每个位置可同时利用两侧的可见上下文（MLM 输入含替换或掩码）。
  • 双向带来一个问题：不能再用标准的"预测下一个词"当训练目标了（因为模型已经能看到答案），所以 BERT 用 Masked Language Modeling（MLM）：随机选出 15% 的 WordPiece token 位置作为预测目标；其中 80% 换成 [MASK]、10% 换成随机 token、10% 保持原样。Loss 只在选中的位置计算；实际换成 [MASK] 的比例约为全体 token 的 12%。老师第 183 页已明确给出这个规则。
  • 第二个训练目标：Next Sentence Prediction（NSP），判断两句话是不是原文里相邻的句子。（RoBERTa 在其训练设置下移除了 NSP，并取得更好的结果；不宜推广成所有任务中 NSP 都无用。）
  • BERT Base：12 层，768 维，12 个头，110M 参数；BERT Large：24 层，1024 维，16 个头，340M 参数。BERT 使用可学习的绝对位置 embedding，并加上 segment embedding，不能直接套用上节原版 sin/cos。
  • 用法：在 BERT 后面接一个小的分类头，微调（fine-tune）整个网络（老师强调：微调整个网络效果通常比只调最后一层好，这跟 ELMo 的用法不一样）。

GPT / GPT-2 / GPT-3（OpenAI）— Decoder-only

  • 老师第 194 页用“ELMo with transformers”作类比。更准确地说，GPT 是单向 Transformer 语言模型——本质上还是从左到右预测下一个词的语言模型（causal LM），只是把 LSTM 换成了 Transformer Decoder（用上了 Masked Self-Attention）。
  • GPT-2：在 40GB 文本上训练；GPT-3：参数量从 GPT-2 的量级跳到 1750 亿（175B），同时期 T5 到了 110 亿参数。
  • 训练一个这种规模的模型非常贵：老师第 198 页转引的历史单次预训练成本估计（约 2019 年；非当前报价）——BERT Base 约 $500，BERT Large 约 $7000，XLNet（BERT 变体）$30,000~$60,000。
补充：三种架构的分类，面试必会
架构代表模型能不能看到未来典型用途
Encoder-onlyBERT, RoBERTa双向，能看到整句分类、NER、句子理解类任务
Decoder-onlyGPT-1/2/3, LLaMA单向，只能看过去（causal mask）文本生成、对话、现代大部分 LLM
Encoder-Decoder原始 Transformer, T5, BARTEncoder 双向 + Decoder 单向 + Cross-Attention翻译、摘要等"输入→输出"任务

T5（2019/2020，Google）— Encoder–Decoder 补充训练目标

老师第 203 页列出了 T5 的 11B 规模。T5 将任务统一为 text-to-text；代表性预训练目标是 span corruption：把输入中连续片段替换为 sentinel token，Decoder 自回归生成被删去的片段及对应 sentinel，而不是逐位置做 BERT 式 MLM。

拓展：预训练与后训练
预训练先学语言或去噪任务；指令微调再学按要求回答，偏好训练可用 RLHF 等方法。RLHF 在 ChatGPT 之前已有研究与应用，不是从 GPT-3.5 才开始。Scaling law 描述特定实验范围内 loss 与模型、数据、算力的经验关系，不意味着只增参数就一定更好。对于未公开结构细节的商业模型，不凭品牌名称断言其精确 Block 或位置编码。

12一页总结 + 面试高频问题

核心一句话

Transformer = 用 Self-Attention（配合 Q/K/V、多头、缩放）替代 RNN 的循环结构，再加残差连接、LayerNorm、Feed-Forward 子层堆叠成的架构，天生支持并行计算、擅长长距离依赖。

为什么能替代 RNN

RNN 必须一步步串行传递隐藏状态；Self-Attention 任意两个词的"距离"都是 1 步，各位置都依赖本层同一份输入，可同时计算，减少序列递推瓶颈；Attention 打分和聚合通常为 O(n²d)，长序列仍有计算成本。

Encoder vs Decoder 关键区别

Encoder 通常无 causal mask，可双向关注（仍可有 padding mask）；Encoder–Decoder 中的 Decoder 用 causal Self-Attention 加 Cross-Attention。GPT 的 Decoder-only 通常没有 Cross-Attention。

BERT vs GPT 关键区别

BERT = Encoder-only + Masked LM，双向，适合理解类任务；GPT = Decoder-only + 标准从左到右语言模型，适合生成类任务。

0Why Transformer? The limitations of RNNs

Before Transformer, a common translation system used an RNN/LSTM encoder to read the source sequence into a fixed-size representation, and a decoder to generate the translation. Long sequences place pressure on that representation and on the LSTM's ability to retain information over many steps.

Ritter's PDF page 114 emphasizes these two long-sequence problems. A separate architectural limitation is sequential computation: an RNN state depends on the previous state, so positions within one sequence cannot all be computed at once. Different examples can still be batched.

Analogy
Imagine listening to an entire lecture, retaining only a short summary, and answering every later question from that summary.

Attention relaxes the information bottleneck: each decoding step can access all encoder states and form a weighted combination instead of relying only on a final summary vector.

1Attention: retrieve information when needed

For decoder position i, score every encoder position j, normalize the scores over j, and combine the encoder states.

eij = f(h̄i, hj)
αij = softmaxj(eij)
ci = Σj αij hj

Here h̄ is a decoder state, h is an encoder state, e is a scalar compatibility score, α is a nonnegative weight, and c is a context vector. The weights over valid positions sum to one.

Scoring methodFormula
Additive — Bahdanau et al. (2014)vaᵗ tanh(Wa[h̄i; hj] + ba)
Dot product — Luong et al. (2015)h̄iᵗ hj
Bilinear — Luong et al. (2015)h̄iᵗ W hj

The lecture's additive formula is abbreviated: after tanh, a projection is needed to obtain a scalar. Encoder states carry source information; decoder states help select what to attend to.

Analogy
In an open-book exam, each question guides you toward relevant pages rather than requiring one memorized summary of the whole book.

2Self-Attention: positions attend within one sequence

In self-attention, queries, keys, and values originate from the same sequence. In the bidirectional example here, each position can attend to every position, including itself, to form a contextual representation.

αi,j = softmaxj(xiᵗxj)
x′i = Σj αi,j xj

This is the lecture's simplified version: Q=K=V=X, with projections and scaling omitted.

Redrawn from lecture page 156. These weights are illustrative, not model measurements or fixed linguistic relationships. In standard Transformer, the weighted contents are projected Values.

Any two permitted positions have a direct information path through one attention layer. An RNN passes information through intermediate states, while a local CNN needs enough layers to connect distant positions.

All outputs in one attention layer use the already available input to that layer, so positions can be computed simultaneously. They are not statistically independent. Dense attention scoring and aggregation typically cost O(n²d); actual speed depends on sequence length, hardware, and implementation.

3Query, Key, and Value

Q
Query: what information am I looking for?
K
Key: how should others match against me?
V
Value: what information do I contribute?

Like a library search, the query is the search request, keys are searchable labels, and values are the contents returned as a weighted mixture. Attention weights are learned compatibility signals, not necessarily human-interpretable semantic similarity.

Q=XWQ, K=XWK, V=XWV
Attention(Q,K,V)=softmax(QKᵗ/√dk)V

X contains one token representation per row. In deeper layers these are contextual hidden states, not simply the original word embeddings. The projection matrices are learned; softmax is applied across key positions.

Notation correction
The lecture's Wk is the bilinear scoring matrix for head k, not the standard Key projection WK. With column-vector projections q=Akx and k=Bkx, qiᵗkj=xiᵗAkᵗBkxj. Thus the lecture's matrix summarizes both projections; scaling is added separately. Its Vk transforms the values.

Separating Q/K/V lets the model learn different representations for requesting information, being matched, and providing content.

4Scaled dot-product attention: why divide by √d?

The lecture's simplified score omits the scaling factor. In standard scaled dot-product attention, dk is the query/key dimension of one head.

Attention(Q,K,V)=softmax(QKᵗ / √dk)V

Under the idealized assumption that query and key components are independent, have mean zero, and have variance one, their dot product has variance dk. Dividing by √dk makes that variance one.

Large score differences can produce a highly concentrated softmax distribution with very small gradients. Scaling reduces this tendency. Learned Q/K need not satisfy the assumptions exactly; the calculation explains the motivation rather than guaranteeing a particular distribution.

Interview checkpoint
Explain the chain: higher dimension → larger dot-product variance under the assumptions → possible softmax saturation → smaller gradients.

5Multi-Head Attention

Ritter compares multiple heads to different convolution filters. Heads use different learned projections and can capture different relationships or representation subspaces. A head might attend to nearby words or a distant referent, but these roles are not prescribed or guaranteed.

Lecture notation (column vectors):
αk,i,j=softmaxj(xiᵗWkxj)
x′k,i=Σj αk,i,jVkxj

Standard notation (rows in X):
headr=Attention(XWQr, XWKr, XWVr)
MultiHead(X)=Concat(head1, …, headh)WO

Each head projects the entire input into its own space; it does not simply receive a fixed slice of the original embedding. Head outputs are concatenated and passed through an output projection.

6Positional Encoding

Without positional signals or a causal mask, self-attention is permutation equivariant: reordering input tokens reorders the outputs correspondingly. It cannot distinguish token order from content alone. The output vectors are not all identical; order-insensitive pooling would produce the same pooled result for permutations.

The original Transformer adds same-width sinusoidal encodings to token embeddings:

PE(pos,2i)=sin(pos/100002i/d)
PE(pos,2i+1)=cos(pos/100002i/d)

Here d is dmodel. Across paired sine/cosine dimensions:

PE(p)ᵗPE(q)=Σi cos((p−q)/100002i/d)
Correct the simplified intuition
This depends on relative distance but oscillates. A smaller distance does not guarantee a larger dot product in every comparison. The original paper compared fixed sin/cos encodings with learned positional embeddings, not raw one-hot vectors. A learned projection of one-hot positions can implement an embedding lookup.

RoPE rotates Q/K using position-dependent angles so their attention scores reflect relative position. Longer-context extrapolation still depends on training lengths, frequency choices, and extension methods; it is not automatic.

7Inside a Transformer Encoder Block

The lecture already includes an Encoder diagram on PDF page 161, with Attention, FFN, and two Add & Norm operations. The original guide's claim that no internal structure was shown was incorrect.

The original 2017 Transformer uses a Post-LN block:

Input x
Multi-Head Self-Attention
Add sublayer input → LayerNorm
Position-wise FFN: Linear → ReLU → Linear
Add sublayer input → LayerNorm
Output → next Encoder Block
z=LayerNorm(x+SelfAttention(x))
out=LayerNorm(z+FFN(z))
FFN(z)=max(0,zW₁+b₁)W₂+b₂
Dropout omitted for clarity.

Residual connections provide a direct path around each sublayer and help optimize deep networks. Each residual adds that sublayer's own input, not always the original input to the entire block.

LayerNorm computes statistics over a token's hidden dimensions, then applies learned scale γ and offset β:

LN(x)=γ⊙(x−μ)/√(σ²+ε)+β

The final output is not guaranteed to have mean zero and variance one. Unlike BatchNorm, LayerNorm does not depend on batch statistics.

The FFN acts independently at each position, with weights shared across positions within a layer. For the original Encoder Block with dff=4d, FFN weights total about 8d² and attention projections about 4d². Thus the FFN accounts for about two-thirds of block weights, ignoring biases and normalization; the whole-model share also depends on embeddings.

Common variants
Pre-LN instead computes z=x+Attention(LN(x)), then out=z+FFN(LN(z)). Other models may use RMSNorm, GELU, or gated FFNs. The original diagram is not an exact specification for every LLM.

8Decoder: Causal Self-Attention and Cross-Attention

Ritter notes that the decoder consumes previously generated tokens and attends to the input, without an RNN-style recurrent state. The following flow describes the original Encoder–Decoder architecture:

Token embedding + position encoding
Training: shifted targets; inference: generated prefix
Masked Multi-Head Self-Attention
Current and earlier input positions only
Add & LayerNorm
Cross-Attention
Q: Decoder; K/V: Encoder output
Add & LayerNorm
Feed-Forward Network
Add & LayerNorm
Repeat these three sublayers for N Blocks
Then Linear to vocabulary → softmax → next token

Each Add uses its sublayer's input as the residual. The normalization order is Post-LN. A GPT-style Decoder-only block normally has no Encoder Cross-Attention sublayer.

Causal Self-Attention

Training supplies shifted target tokens. Without a mask, an output position could read its target from a later input position. Set forbidden attention scores to −∞ before softmax so their weights become zero:

scorei,j=(QKᵗ/√dk)i,j if j≤i; otherwise −∞

The current input position is allowed because the targets have been shifted. This aligns which positions are visible during training and inference. Their prefixes still differ: ground truth in training versus model-generated tokens at inference, creating exposure bias.

Cross-Attention

Queries come from the current decoder representations after the masked sublayer. Keys and values are projections of the final Encoder output. This implements the same source-retrieval idea as RNN encoder–decoder attention using the Transformer Q/K/V formulation.

SublayerQ sourceK/V source
Encoder Self-AttentionEncoder layer inputSame input sequence
Decoder Causal Self-AttentionTarget-prefix layer inputSame prefix; only allowed positions
Decoder Cross-AttentionDecoder representationsFinal Encoder output

9Training versus inference: Teacher Forcing

The lecture describes feeding correct previous tokens when training an RNN decoder. The same Teacher Forcing principle applies to Transformer decoders.

  • Training: use the ground-truth prefix to predict the next target. In a Transformer, shifted targets and a causal mask allow all target losses to be computed in parallel. An RNN still has sequential hidden-state dependencies even with Teacher Forcing.
  • Inference: use the generated prefix. Ordinary autoregressive generation proceeds token by token until EOS (called [STOP] in the lecture) or a length limit.

Interview checkpoint
During training the target prefixes are already known. During ordinary autoregressive inference, the next prefix depends on the token just generated. This is why parallel training does not imply parallel generation of an unknown output sequence.

10Tokenization: BPE and WordPiece

The lecture does mention approximately 30k WordPiece tokens on page 185, but does not explain vocabulary training algorithms. Transformer operates on tokens; a token can be a whole word, part of a word, punctuation, or a whitespace-related piece. The architecture does not require a particular tokenizer.

A whole-word vocabulary can be large and often maps unseen words to [UNK], losing their identities. Subword vocabularies can express many unseen words as known pieces. Character coverage can still cause [UNK]; complete byte coverage avoids that vocabulary-coverage issue.

  • BPE: repeatedly merge frequent adjacent token pairs. Character-level BPE starts from characters; GPT-2's byte-level BPE starts from bytes. Frequent words may be single tokens, while rare words may split into pieces. For example, “un” + “happi” + “ness” is only an illustration; actual splits depend on the tokenizer.
  • WordPiece: used by BERT, with continuation pieces such as ##ing. Vocabulary training is often explained using a vocabulary language-model likelihood objective. It is not the Transformer LM's training likelihood. BERT released its tokenizer and vocabulary, not a complete original vocabulary-training implementation. The teaching score freq(ab)/(freq(a)freq(b)) is a useful illustration, not a verified exact description of BERT's original training rule.
Interview checkpoint
Explain vocabulary size, unseen words, compositional pieces, and the distinction between words and tokens.

11Transformer families: BERT, GPT, and T5

BERT — Encoder-only (2018)

ELMo combines a forward and a backward LSTM language model into a bidirectional LM, but each direction models context separately. BERT jointly integrates visible context from both directions using an Encoder without a causal mask.

  • MLM: select 15% of WordPiece positions as prediction targets. Of those, replace 80% with [MASK], 10% with random tokens, and leave 10% unchanged. Compute the MLM loss only at selected positions. Approximately 12% of all positions therefore become [MASK]. The lecture explicitly gives this rule on page 183.
  • NSP: distinguish the actual next text segment from a randomly sampled segment. RoBERTa removed this objective in its training setup; that does not prove NSP is useless in every setting.
  • Base: 12 layers, width 768, 12 heads, 110M parameters. Large: 24 layers, width 1024, 16 heads, 340M parameters.
  • BERT uses learned absolute position embeddings and segment embeddings, not the original fixed sin/cos scheme.
  • For downstream tasks, add a suitable head and fine-tune. The lecture notes that tuning the whole network often outperforms tuning only the head, unlike the typical frozen-ELMo feature workflow.

GPT — Decoder-only

The lecture's “ELMo with transformers” phrase is a rough analogy. GPT is a single left-to-right Transformer language model trained to predict the next token. A standard GPT block uses causal Self-Attention without the Encoder Cross-Attention in the original translation decoder.

Historical lecture figures: GPT-2 trained on 40GB of text; the largest GPT-3 has 175B parameters; T5 reaches 11B. Page 198 quotes approximately 2019 single-pretraining-run cost estimates: BERT Base $500, Large $7,000, and XLNet $30,000–$60,000. These are historical estimates, not current prices or costs for GPT-3.

ArchitectureExamplesAttention patternTypical uses

T5 — Encoder–Decoder (2019/2020)

The lecture lists T5's scale on page 203. T5 frames tasks as text-to-text. Its representative pretraining objective is span corruption: replace contiguous spans with sentinel tokens, then have the Decoder autoregressively generate the removed spans and corresponding sentinels.

Pretraining and post-training
Pretraining learns language or denoising tasks. Instruction tuning teaches responses to instructions; preference training can use RLHF. RLHF research and applications predate ChatGPT. Scaling laws are empirical relations within particular experimental ranges, not a guarantee that more parameters alone are better. Do not infer the exact blocks of undisclosed commercial models from their names.

12Summary and interview self-check

Core idea

Use attention to exchange information among positions, and FFNs to transform each position, with residual connections and normalization.

Parallelism

Positions within a Transformer layer can be computed together from the available layer input. Dense attention still has quadratic sequence-length cost.

Encoder versus Decoder

An Encoder is typically bidirectional. An Encoder–Decoder decoder adds causal attention and source Cross-Attention. GPT-style Decoder-only normally omits that Cross-Attention.

Training objectives

BERT: MLM + NSP originally. GPT: next-token causal LM. T5: span corruption in a text-to-text framework.
