# Transformer Study Guide · Transformer 中英文复习指南

A reviewed Chinese/English study guide based on Alan Ritter’s Neural Networks for Text lectures.
基于 Alan Ritter 的 Neural Networks for Text 课件，核对并修订的中英文复习指南。

## Read / 阅读

Download [`transformer-study-guide-bilingual.html`](transformer/transformer-study-guide-bilingual.html) and open it in a browser. Use **中文 / English** to switch languages. The page works offline; paper references link to external websites. GitHub’s file view displays HTML source rather than rendering the guide.

下载 [`transformer-study-guide-bilingual.html`](transformer/transformer-study-guide-bilingual.html)，用浏览器打开。点击 **中文 / English** 切换语言。课件可离线阅读，论文链接需要联网；GitHub 文件页显示 HTML 源码。

## Topics / 内容

RNN limitations, Attention, Self-Attention, Q/K/V, scaling, multiple heads, positions, Encoder/Decoder blocks, Teacher Forcing, tokenization, BERT/GPT/T5, and interview self-checks.

涵盖 RNN 痛点、注意力、Q/K/V、缩放、多头、位置编码、Encoder/Decoder、Teacher Forcing、分词、BERT/GPT/T5 和自测题。

## Review / 核对

The guide corrects notation, BERT’s 80/10/10 corruption scheme, positional-encoding claims, lecture attribution, and diagram omissions. It includes original PDF page references and links to research papers. Illustrative attention weights are not model measurements.

已修正记号对应、BERT 掩码规则、位置编码的过度概括、课件内容归属和图示遗漏。包含原 PDF 页码和论文链接。图中注意力权重仅为示意。

This is an independent study aid, not an official course publication. Original lecture PDFs are not included.
这是独立整理的学习材料，并非课程官方发布；不包含老师的原始 PDF。
